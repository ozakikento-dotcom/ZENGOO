# 今日の禅語 Part 1

収録期間：1月1日〜6月30日（181日）

## 仕様
- 表示項目：禅語・読み・意味
- 同一語の重複なし
- 造語を避け、禅籍・禅林句・公案・茶掛として伝承される語句を採用
- GitHub Pages対応

## 公開方法
このフォルダの内容をGitHubリポジトリのルートへ配置し、Pagesを有効化してください。

## データ
- `data/all.json`：181件統合データ
- `data/01.json`〜`06.json`：月別データ

## 注記
読みには複数の慣用がある句もあります。本版は茶席・禅門で一般的に用いられる読みを基本にしています。
